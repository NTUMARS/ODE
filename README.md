# ODE Policy project page

Static project page for *ODE Policy: Robot Learning via Action Dynamics, Not Actions* ([arXiv:2611.01729](https://arxiv.org/abs/2611.01729)) (MARS Lab, NTU).

- `page.html` is the source. Run `python3 build.py` to regenerate `index.html`, which GitHub Pages serves.
- Figures and robot images are in `assets/`.
